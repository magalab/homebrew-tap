# Casks

Available casks in this tap:

- [alacritty](alacritty.rb) — Alacritty terminal emulator for Apple Silicon
- [idev](idev.rb) — 一些开发工具
- [meow](meow.rb) — Meow app for macOS
- [miao](miao.rb) — Miao app for macOS
- [winc](winc.rb) — Lighter, faster, more comfortable desktop editor

## Install

```bash
brew install --cask <cask-name>
```
